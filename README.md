## Jibril Releases

Automated release artifacts for Jibril, Garnet's Linux runtime sensor.

Jibril records runtime activity at the kernel and is built and maintained by Garnet Labs Inc. This repository publishes release binaries only; Jibril source code is not published here.

The "Garnet GitHub Action" (https://github.com/garnet-org/action) pins and downloads Jibril binaries from "Releases" (https://github.com/garnet-org/jibril-releases/releases).
